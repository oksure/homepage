이곳은 GitHub Pages 실습을 위해 만든 개인 홈페이지입니다. 자기소개, 프로젝트, 관심 분야 등을 자유롭게 바꿔 넣을 수 있습니다.

Step 1. HTML 파일 만들기 기본 문서 구조를 만들고 내용을 채웁니다.
Step 2. 디자인 적용하기 style 태그 안에 CSS를 작성해 홈페이지를 꾸밉니다.
Step 3. GitHub Pages 배포하기 index.html 파일을 저장소에 올리고 웹사이트로 공개합니다.
